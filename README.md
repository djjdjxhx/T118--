# Трекер ошибок (Практическая работа T118)

## Реализованные возможности
В программе реализована обязательная база учебного журнала ошибок (задания 1–4):
1. Просмотр всех ошибок — вывод текущего списка записей.
2. **Поиск по ID (find_bug)** — поиск конкретной ошибки по её уникальному идентификатору.
3. **Фильтрация (filter_bugs)** — отбор записей по статусу и степени серьёзности.
4. **Добавление ошибки (add_bug)** — создание новой записи с автоматическим расчётом уникального ID и проверкой длины названия (минимум 5 символов).
5. **Управление статусом (change_status)** — изменение статуса ошибки с соблюдением правил переходов между состояниями (open, in_progress, closed).
6. **Интерактивное меню** — управление через консольный цикл с защитой от ввода некорректных данных (например, букв вместо ID).

## Запуск программы
1. Убедитесь, что на компьютере установлен Python (версии 3.8 или выше).
2. Сохраните код программы в файл (например, main.py).
3. Откройте терминал (командную строку) в папке с этим файлом.
4. Выполните команду для запуска:
   `bash
   python main.py
